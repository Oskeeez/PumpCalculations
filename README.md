# Pump & Pipe Hydraulic Calculator

Client-side pump/pipe hydraulic calculator (Vite + React + TypeScript). SI units internally.

- `src/solver/` – pure TypeScript solver library (no UI/React deps).
- `tests/` – Vitest unit tests (`npm test`); `tests/validation/` holds Crane TP-410 / EPANET placeholders.

Status: solver + tests complete; UI and Excel export pending.
